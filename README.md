## Local preview

The published site is static HTML. Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8000`.

Optional template tooling (SCSS / vendor copy) still lives in `package.json` from the original Start Bootstrap Resume theme:

```bash
npm install
npm start
```
